# Stock Portfolio Analyzer

## Project Overview

Stock Portfolio Analyzer is a Python-based financial analysis project that helps users analyze their stock investments and understand their portfolio performance.

The program calculates investment-related metrics and identifies the best-performing stock in the portfolio.

## Features

- Calculate total investment value.
- Calculate current portfolio value.
- Count profitable stocks.
- Count stocks making a loss.
- Count stocks with no change in value.
- Identify the best-performing stock based on percentage return.
- Display portfolio performance.

## Technologies Used

- Python 3
- VS Code

## Python Concepts Used

- Variables and data types
- User input and output
- Conditional statements
- Loops
- Lists
- Basic arithmetic operations

## How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python portfolio_analyzer.py
```

5. Enter the required stock information when prompted.
